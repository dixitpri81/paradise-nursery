# Paradise Nursery Shopping Application

## Project Overview

**Paradise Nursery** is a dynamic, full-featured e-commerce web application built with React and Redux Toolkit. It allows users to browse a curated collection of houseplants, explore product details, and manage a fully functional shopping cart.

## Project Name

**Paradise Nursery – Plant Shop**

## Tech Stack

- **Frontend:** React 18, JSX
- **State Management:** Redux Toolkit (RTK)
- **Styling:** CSS3, Flexbox, Grid
- **Build Tool:** Vite

## Features

- 🌿 Browse 18+ unique houseplants across 3 categories
- 🛒 Add plants to cart with one click
- 📦 View cart with quantity controls and cost breakdown
- 💰 Dynamic total cost calculation
- 🔢 Live cart item count in navigation bar
- 📱 Responsive and user-friendly design

## Plant Categories

1. **Tropical Plants** – Monstera, Bird of Paradise, Fiddle Leaf Fig, Anthurium, Philodendron, Heliconia
2. **Succulents & Cacti** – Aloe Vera, Jade Plant, Echeveria, Barrel Cactus, Haworthia, Agave
3. **Air Purifying Plants** – Peace Lily, Spider Plant, Snake Plant, Pothos, Rubber Plant, Boston Fern

## Getting Started

```bash
npm install
npm run dev
```
